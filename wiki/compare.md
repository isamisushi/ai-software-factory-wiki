[← Home](../) · [Cases](index.md) · [Concepts](concepts.md) · [Loops](loops/index.md)

This table compares ten cases across the same topics. Each case page records its research date, target commit, and evidence. Topic links lead to definitions.

Implementation means a condition found in the inspected code. Instructions or specifications describe required behavior. Public descriptions report what the operator says.

Reading code does not establish enforcement in a live deployment or successful execution tests. Unconfirmed does not mean that a feature is absent.

A PR is a pull request for a code change. CI runs automated tasks after code changes. A SHA identifies a specific commit.
